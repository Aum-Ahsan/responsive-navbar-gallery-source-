# Responsive Navbar Gallery

Twenty-seven responsive navbar components and twenty reusable hero sections built with React, Node.js and Tailwind CSS.

- `components/navbars/navbar-01` through `navbar-27`: individual navbar source
- `components/navbars/shared`: responsive shell and shared primitives
- `components/heroes/hero-01` through `hero-20`: individual hero source
- `components/heroes/shared`: reusable hero layout and visual system
- `app/globals.css`: shared typography and global CSS
- `app/page.tsx`: ordered showcase with Desktop, Tablet and Mobile controls

Run with `npm run dev` and build with `npm run build`.
